🎯 Projenin Amaci

WebSecure, hedef web uygulamalarini ve altyapiyi otomatik olarak tararken insan penetrasyon testçisinin yaptigi tüm teknikleri uygular. Tek bir komutla:

  • Subdomain tespiti ve port tarama yapar
  • Tüm endpointleri crawl eder (HTTP + JS-render)
  • 36 farkli güvenlik acigi kategorisini test eder
  • Bulunan aciklari otomatik exploit eder
  • Exploit zinciri olusturur (ör: SQLi → CredDump → ATO)
  • Post-exploitation (veri calma, pivot, kalicilik) saglar
  • HTML/SARIF/JUnit/PDF/Markdown rapor üretir
  • CI/CD pipeline'ini critical bulgu oldugunda durdurur
🌍 Hedef Kullanici Kitlesi
  • Bug Bounty Avcilari — bug_bounty.yml profili, OAST, agresif WAF bypass
  • Penetrasyon Testçileri — tam exploit zinciri, post-exploit, playbook destegi
  • DevSecOps Ekipleri — CI/CD entegrasyonu, SARIF çiktisi, otomatik bildirim
  • Güvenlik Denetçileri — OWASP/PCI-DSS/GDPR uyumluluk profilleri
  • Red Team — WAF bypass, insan davranis simulasyonu, Tor destegi
